# Tasty Recipes 🍝

A simple, responsive React web application that showcases a collection of delicious recipes using functional components, props, lists, conditional rendering, and event handlers.

---

## 📌 Project Overview
This project was built as a beginner-friendly practice exercise to solidify foundational React concepts. It features a modern recipe showcase where users can explore various dishes, check their popularity status, and interact with recipe details.

---

## ✨ Features
* **Dynamic Recipe Rendering:** Displaying multiple recipe cards from an array of data using JavaScript `map()`.
* **Component-Based Architecture:** Reusable components including `Navbar`, `Hero`, `RecipeCard`, `RecipeList`, and `Footer`.
* **Conditional Badges:** Automatically displays a `🔥 Popular` badge for highlighted recipes.
* **Interactive Buttons:** `onClick` event handling on recipe cards to display quick interactive alerts.
* **Fully Responsive Design:** Optimized layout using CSS Grid and Flexbox for seamless browsing across mobile, tablet, and desktop devices.

---

## 🛠️ Built With
* **React** (JSX, Components, Props, Map, Events, Conditional Rendering)
* **CSS3** (CSS Variables, Flexbox, Grid, Media Queries)
* **Vite** / **Create React App**
